# Learning Notes

This folder captures reusable lessons from the development process. It is a
study companion to the chronological logbook.

Use these notes for concepts that are worth revisiting later:

- Git workflow habits.
- Architecture and design rationale.
- Embedded C++ practices.
- Testing strategy.

The logbook explains when and why a topic came up. Learning notes explain the
topic itself in a reusable form.

## Files

- `git-workflow.md`: branches, commits, remotes, stashing, merging, semantic commits.
- `architecture-decisions.md`: design tradeoffs and structure rationale.
- `embedded-cpp.md`: embedded C++ style, memory, timing, comments, Arduino pitfalls.
- `testing.md`: native tests, fakes, bench tests, and verification strategy.
